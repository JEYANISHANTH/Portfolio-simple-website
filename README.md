💼 Simple Portfolio Website

This is a basic portfolio website created using only HTML and CSS. It includes two pages:

🧑‍💻 Profile Page – Contains a short bio, skills, and a brief introduction.

✉️ Contact Page – Provides contact details or a simple contact form layout.

The main purpose of this project is to practice the fundamentals of web development using only HTML and CSS, with no JavaScript or external frameworks.

🛠️ Built With

HTML5

CSS3 (basic styling, responsive layout)

📌 Features

Clean and simple design

Responsive layout (mobile-friendly)

Easy navigation between pages
